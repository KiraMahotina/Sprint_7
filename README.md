# Автотесты API для сервиса доставки самокатов

[![Python](https://img.shields.io/badge/Python-3.9%2B-3776AB?logo=python)](https://python.org)
[![Pytest](https://img.shields.io/badge/Pytest-7.4.0-0A9EDC?logo=pytest)](https://docs.pytest.org)

Автоматизированные тесты для проверки API сервиса **QA Scooter** (`https://qa-scooter.praktikum-services.ru`).

## 🛠 Технологии
- **Python 3.9+**
- **Pytest** — фреймворк для тестирования
- **Requests** — отправка HTTP-запросов
- **Allure** — генерация отчетов

## 🚀 Быстрый старт
1. Установите зависимости:
pip install -r requirements.txt
Запустите тесты:


pytest --alluredir=allure-results
Откройте отчет:
allure serve allure-results
